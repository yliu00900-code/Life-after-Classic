# LifeAfter Classic

一个致敬 2018 年《明日之后》第一季氛围与生存循环的原创单机复刻项目。

> 本项目是独立爱好者作品，使用原创代码与原创/合法授权素材；不包含网易官方客户端、官方源代码或未经授权的原版游戏资源，也不代表网易官方。

## 当前版本：V0.8 STORY

仓库已有可运行的浏览器端第三人称 3D 原型（入口：`index.html`），目前包含：

- 秋日森林风格的原创 3D 场景、第三人称镜头和手机虚拟摇杆
- 树木/石块采集、资源背包与本地存档
- 感染者巡逻、追击和战斗
- 生存状态、昼夜与天气氛围
- 制作、营地建造、幸存者 NPC、主线任务与剧情对话

**运行方式：** 在支持 WebGL 的浏览器中打开项目页面。当前 Three.js 通过 jsDelivr CDN 加载，因此首次运行需要联网；这还不是完全离线版本，也不是已打包的 Android APK。

## 技术方向

当前为 HTML + JavaScript + Three.js 的移动浏览器原型，优先确保安卓手机可以操作和验证。后续先把运行依赖和资源全部本地化，再进行离线 APK 打包。

## 当前限制

- 浏览器版本依赖 WebGL；当前 Three.js 仍从 CDN 加载。
- 本地存档保存在浏览器 localStorage，清除网站数据会丢失。
- 当前地图、角色、剧情和素材为独立原创原型，不是官方第一季客户端的完整复原。
