# LifeAfter Classic

一个致敬 2018 年《明日之后》第一季氛围与玩法的原创 3D 废土生存游戏原型。

> 本项目为独立爱好者项目，使用原创代码与素材或合法授权资源，不包含官方游戏客户端、受版权保护的原版资源或官方背书。

## 项目目标

优先面向安卓设备，逐步制作可运行的第三人称 3D 生存探索原型，重现早期末日废土探索的氛围。

## 开发路线

- [ ] **V0.1 场景与移动**：秋日森林风格的原创森林场景、第三人称角色移动、虚拟摇杆与相机控制
- [ ] **V0.2 采集与背包**：资源采集、物品栏与基础资源管理
- [ ] **V0.3 战斗与感染者**：感染者基础 AI、武器与战斗反馈
- [ ] **V0.4 生存氛围**：昼夜、天气、雾效与生存状态
- [ ] **V0.5 制作与建造**：基础制作、庄园与建造系统
- [ ] **V0.6 远星城风格区域**：原创 PVP 风格探索区域与风险机制
- [ ] **V1.0 安卓离线版**：依赖本地化、离线运行与安卓打包测试

## 技术方向

原型阶段优先评估 Three.js / JavaScript，以移动浏览器可运行的方式验证核心玩法；后续再处理资源本地化、性能优化与安卓 APK 打包。

## 当前状态

仓库初始化完成。当前尚未提交可运行的游戏原型代码；下一阶段从 V0.1 场景与第三人称移动开始。

## 设备与测试约束

开发流程优先考虑安卓手机可操作性。每个里程碑都应说明如何在安卓设备上运行和验证，并明确区分已完成、未验证与待完成事项。
