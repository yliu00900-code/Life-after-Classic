# 第一季复刻设计基线

## 目标定义

目标是制作一款独立、可离线运行的第三人称 3D 生存手游，以 2018 年《明日之后》第一季给人的探索节奏、镜头距离、废土色调、资源循环和营地成长感为参考。它不是官方客户端的源码恢复，也不使用未经授权提取的地图、模型、贴图、角色、音乐或语音。

## 画面基线

- 镜头：第三人称越肩跟随，角色位于屏幕下方中央；右侧触摸区域控制镜头，左侧虚拟摇杆移动。
- 环境：低饱和秋林、潮湿泥地、枯草、倒木、破损道路、废弃营地；远景使用雾效控制视距。
- 光照：偏冷环境光与低角度暖色主光；阴天、薄雾、夜间和降雨使用不同天空/雾色。
- 材质：树皮、粗糙石材、旧金属、潮湿木板和布料采用不同粗糙度；避免过度鲜艳和塑料感。
- 性能：先确保中端安卓设备稳定帧率，再逐步提高植被密度、阴影质量和场景细节。

## 第一季核心循环

1. 离开安全营地，进入野外区域。
2. 观察环境与危险，采集木材、石料、植物纤维和食物。
3. 与感染者交战或绕行，搜寻箱柜、废弃设施和线索。
4. 返回营地，整理背包、制作工具/武器、补充生存物资。
5. 通过任务与探索解锁新区域、装备配方和建造设施。

## 系统优先级

### P0：必须可靠
- 安卓触控：摇杆、镜头拖动、交互、攻击、背包和面板关闭。
- 存档：角色位置、背包、资源节点状态、建筑、任务和生存状态持久化。
- 战斗：敌人感知、追击、攻击距离、受击反馈、死亡和掉落。
- 离线：所有运行时代码、模型、贴图、音频都必须打包到应用内。

### P1：经典生存体验
- 采集工具耐久与采集动作反馈。
- 武器类别、弹药、装填、近战和基础装备成长。
- 饥饿、口渴、体温、天气与昼夜对生存的影响。
- 营地设施、储物箱、工作台、篝火和建筑摆放。

### P2：区域与内容扩展
- 秋日森林：首个完整可玩区域，含安全屋、河道、伐木点、采石点、废弃营地和撤离路线。
- 远星城风格区域：更高风险、开阔街区、资源争夺与敌对威胁；使用原创布局和素材。
- 沙石堡风格区域：干旱环境、遗迹、沙尘天气与不同资源循环；使用原创布局和素材。
- NPC、支线、区域事件、探索日志与多章节主线。

## 资产与授权规范

- 优先使用自制模型、程序化几何、原创贴图与原创音效。
- 第三方资产必须记录名称、作者、来源 URL、许可证、修改情况和署名要求。
- 不从 APK 提取并重新发布官方代码、地图、模型、贴图、音频或其他受保护资产。
- 玩家提供的参考截图只用于理解视觉方向，不自动授予其中素材的再利用权。

## 里程碑验收

- M0 工程化：Vite 构建成功；Three.js 运行时来自 npm bundle；Android debug APK 能生成。
- M1 离线可运行：断网启动、加载场景、移动、采集、战斗、保存/读取均通过。
- M2 秋日森林垂直切片：一个可探索区域、两类资源节点、一种感染者、一个营地、一条任务线。
- M3 生存与成长：工作台、武器升级、消耗品、储物和建造闭环。
- M4 内容扩展：新区域、新敌人、新装备和剧情。

## 当前风险与验证项

- 当前项目是 Three.js 原型，不是完整的官方第一季复刻；地图与角色资产仍需重制。
- Vite/Capacitor 工作流刚加入，必须等待 GitHub Actions 首次构建结果，不能把“已配置”误称为“APK 已构建成功”。
- 安卓机型性能、WebView 兼容性、触控误触和存档行为必须在真机测试。
